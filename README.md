# Atelier des rêves — distribution

Application Android personnelle et expérimentale de **mémoire des rêves** :
immersion audiovisuelle avant le coucher, diffusions musicales nocturnes,
réveil musical, dictée vocale des rêves au réveil et journal privé.

- 🇫🇷 Entièrement en français — **100 % hors ligne après installation des médias**
- 🔒 **Aucun compte, aucun serveur** : toutes les données (rêves, audios, réglages,
  sommeil) restent sur le téléphone. Personne ne peut y accéder.
- 💰 Gratuit, sans publicité, sans abonnement.

## Installer

1. Téléchargez l'APK : **[dernière version](https://github.com/Junta357/atelier-des-reves-app/releases/latest/download/AtelierDesReves.apk)**
2. Ouvrez le fichier téléchargé sur votre téléphone Android (8.0 minimum) et
   acceptez l'installation (« sources inconnues » demandé par Android).
3. À la première ouverture, un petit assistant vous guide (horaires, volumes,
   univers). L'application vous préviendra elle-même des mises à jour.

## Univers audiovisuels

Les univers (musique + vidéo, ~45 à 120 Mo chacun) se téléchargent depuis
l'application, onglet **Univers**. Ils fonctionnent ensuite hors ligne.

## Santé

Connexion facultative à **Health Connect** (sessions de sommeil de Samsung
Health, Fitbit, Google Fit et autres applications compatibles). L'application
fonctionne parfaitement sans montre : les horaires se règlent à la main.

## Mises à jour

L'application détecte les nouvelles versions et vous propose l'installation
(avec la confirmation d'Android). Vos données sont conservées.

---

Application expérimentale à usage personnel : aucune garantie médicale ou
scientifique ; les phases de sommeil rapportées par les montres sont des
estimations, pas des mesures cliniques.
